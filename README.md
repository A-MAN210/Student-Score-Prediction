# 🎓 Student Score Prediction System

A Machine Learning project developed during the **AI & ML Internship at Codomax Digital Solutions**.

This project predicts a student's expected exam score based on the number of weekly study hours using the **Linear Regression** algorithm.

---

## 📌 Project Overview

The objective of this project is to build a Machine Learning model that can predict a student's average score from their study hours.

The project includes:
- Data loading and exploration
- Data cleaning
- Data visualization
- Model training
- Score prediction
- Model evaluation
- Python prediction application

## 📈 Machine Learning Algorithm

**Linear Regression**

The model learns the relationship between study hours and student scores and predicts the expected score for new input values.

---

## 📋 Evaluation Metrics

The model performance was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

```bash

```

Open:

```

```

Run all cells.

### Run Prediction App

```bash
python predict_app.py
```
